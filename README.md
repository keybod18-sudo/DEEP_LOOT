# DEEP LOOT local / v4

Vite + TypeScript + Canvas でローカル開発するDEEP LOOTです。

## 起動
`START_LOCAL.bat` をダブルクリック。

## 今回追加したもの
- M / Esc / Tab でメニューを開閉
- ステータス表示（階層 / HP / 攻撃 / 防御 / 所持金 / 装備）
- 武器8スロット
- 防具8スロット
- 回復アイテム8スロット
- 敵撃破時に武器・防具・回復アイテムのいずれかを1個ドロップ
- ドロップに触れると自動取得。対応欄が8個埋まっていれば床に残る
- 武器・防具にはランダムなアビリティを付与
- メニュー内で武器 / 防具をクリックすると装備
- 回復アイテムをクリックすると使用
- 右端に階段を配置
- 階段付近で E / Enter を押すと次のフロアへ
- 次フロア移動時に敵を再配置、床の未取得ドロップをリセット
- 所持品 / 装備 / HP / 所持金はフロアをまたいで維持

## 操作
- A / D または ← / → : 移動
- W / ↑ / Space : ジャンプ
- J : 攻撃
- M / Esc / Tab : メニュー
- E / Enter : 階段で次の階へ


## v6 GitHub運用

初回だけ:

1. `CONNECT_GITHUB.bat`
2. GitHubで空の `DEEP_LOOT` リポジトリを作る
3. URLをBATへ貼る
4. 初回pushが完了

2回目以降:

- `START_LOCAL.bat` → GitHub更新確認 + Vite起動
- `UPDATE.bat` → 更新だけ取得
- Vite起動中なら更新取得後にブラウザへ自動反映

`.runtime/git` にPortable Gitを自動導入するため、グローバルGitの手動インストールは不要です。
